§ 1

Rendering is a sheet of paper on top.
Underneath, every character is yours.

Most WYSIWYG editors rebuild your file from a document model when they save — lists get new markers, blank lines collapse, characters get escaped. Weilanx Markdown only decorates; it never re-serializes. Open a file, fix a typo, and git shows exactly one changed line.

  1. 01

    Paste a screenshot. That's it.

    ⌘V a screenshot, a copied file, or drag one in. It lands in a folder you choose — assets/${fileName}/${date}-${time}.png by default, per workspace if you like — and never overwrites anything. If the webview can't see the image, the extension reads the system clipboard instead.

  2. 02

    Three ways to look at a page

    Locked for reading, Edit for writing with live preview, Source when you want every character in plain sight. One switch at the top right, or ⌘⌥M.

  3. 03

    Your fonts, your measure

    Text size follows VS Code. Body, heading and code fonts, line height, column width and paragraph spacing are one click away in the Aa panel — and save to user or workspace settings.

  4. 04

    Counted the way editors count

    Words (Chinese by character, English by word), characters, speaking time for voice-overs and reading time — in the status bar, for the whole file or just your selection. Hover to check limits for Xiaohongshu, X and WeChat.

  5. 05

    An outline, and the dark

    A sidebar outline that follows you down the page. Every color comes from your VS Code theme, light or dark.

  6. 06

    Tables, code, math, diagrams

    Rounded tables with zebra rows, highlighted code, KaTeX, Mermaid, GitHub alerts and task lists — then export to HTML or PDF.

§ 3

Set the type yourself

These are the same controls as the Aa panel inside the editor. Try them.

The last line of a paragraph

A good measure sits somewhere between forty-five and seventy-five characters. Too narrow and the eye jumps back too often; too wide and it loses its place on the way back.

Line height does the rest. Body text breathes at around one and three quarters; headings can sit tighter.

§ 5

Install

  1. Run the installer, or download the .vsix

    curl -fsSL https://raw.githubusercontent.com/Azure12355/weilanx-markdown/main/scripts/install.sh | bash

    Installs into every VS Code based editor it finds. Or grab weilanx-markdown.vsix and choose Install from VSIX…

  2. Make it your default Markdown editor (optional)

    "workbench.editorAssociations": { "*.md": "weilanxMarkdown.editor" }

  3. Or let your agent do it

    Install Weilanx Markdown for me. Follow https://github.com/Azure12355/weilanx-markdown/blob/main/docs/install-for-agents.md and verify the install.
