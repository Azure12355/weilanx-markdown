# Weilanx Markdown

A live-preview Markdown editor for VS Code that never rewrites your source.

- Live preview: markup hides away from the cursor and comes back when you edit (headings, emphasis, links, images, code, tables, tasks, KaTeX, Mermaid, front matter)
- Paste or drop images directly; storage path is a template you can set per workspace or folder
- Font size follows VS Code by default; body / heading / code fonts, line height, width and paragraph spacing are adjustable from the "Aa" panel
- Outline sidebar, export to HTML and PDF
